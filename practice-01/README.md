## 4. Задание 1: Один файл — две среды выполнения

**Фактический результат:**
* При запуске в браузере вывод последней строки: `Тип document: object`.
* При запуске через Node.js вывод последней строки: `Тип document: undefined`.

**Обоснование:**
Браузер и Node.js представляют собой различные среды выполнения JavaScript-кода. В браузере по умолчанию присутствует объект `document`, предоставляющий интерфейс для взаимодействия с веб-страницей (DOM-деревом). Среда Node.js предназначена для выполнения скриптов вне браузера, она не формирует HTML-страницу и не содержит DOM, вследствие чего объект `document` в ней отсутствует.

**Обоснование некорректности использования исключительно функции `Number()` и проверки на положительное значение:**
Функция `Number()` осуществляет ряд неявных преобразований, которые могут привести к критическим уязвимостям в логике:
1. Вызов `Number("")` или `Number("   ")` возвращает `0`. Отсутствие предварительной проверки на пустую строку приведет к тому, что система интерпретирует пустой ввод как нулевое количество задач, что семантически неверно.
2. Аналогично, `Number(null)` и `Number(false)` возвращают `0`. Строгая проверка типа исходных данных необходима для фильтрации невалидных типов.
3. Использование условия `>= 0` не исключает обработку дробных чисел (например, вызов `Number("2.5")` сохранит значение `2.5`). Поскольку количество задач должно быть строго целым, требуется обязательная проверка посредством метода `Number.isInteger()`.
4. Проверка исключительно на неотрицательность не обеспечивает защиту от превышения установленного верхнего предела (например, ограничения в 1000 задач) и не выявляет логические противоречия (ситуации, когда количество выполненных задач превышает их общее количество).
